# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

One static HTML file with Canvas 2D, inline CSS and JavaScript, and synthesized WebAudio. The game opens directly in a desktop browser and makes zero asset requests.

## Users

Kiroween Costume Contest judges and desktop players who need to start a short survival run with a keyboard and mouse.

## Product Purpose

Survive rising waves in a Halloween arena, choose lasting upgrades, and defeat a boss every five waves. The score records how far each run went.

## Positioning

Walking over a costume replaces the one currently equipped. A change in silhouette and a change in tactics happen together. Eight permanent upgrade cards remain in effect across swaps.

## Operating Context

Start directly from the page or open the file offline. Move with WASD or arrow keys, aim and shoot with the mouse, dash with Space, pause with P, and mute with M. Earn XP, choose a card, and return to the same fight. R starts a fresh run from the results.

## Capabilities and Constraints

Use a 960 × 600 logical arena with high DPI drawing. Keep the visible game text in English, support keyboard navigation of menus, and store the best score locally when the browser allows it. The brief specifies original Canvas artwork and synthesized sound.

## Brand Commitments

Neon Hallows Arena is an original Halloween arcade game. Dark purple ground, violet grid, cyan player, and orange, violet, or green gameplay effects follow the supplied brief.

## Product Principles

- The start screen gets the player into a run quickly.
- A costume changes what the player sees and how they fight.
- Attack cues and threats remain readable under pressure.
- A finished run is immediately replayable.
